# 💀 HellSkull

HellSkull é uma plataforma web desenvolvida para recomendação e catalogação de jogos, permitindo que os usuários descubram novos títulos através de uma interface moderna, intuitiva e organizada.

O projeto foi criado com foco no aprendizado e prática de conceitos fundamentais do desenvolvimento Front-End, incluindo manipulação do DOM, filtros dinâmicos, pesquisa em tempo real e construção de interfaces responsivas.

## ✨ Funcionalidades

- 🔍 Pesquisa de jogos em tempo real
- 🎮 Exibição de jogos em cards organizados
- 🏷️ Filtragem por categorias
- 🌐 Links diretos para as páginas dos jogos
- 📱 Interface responsiva
- 🎨 Design inspirado no universo gamer
- ⚡ Atualização dinâmica dos resultados sem recarregar a página
